# Unclasp site

Support page and privacy policy for the Unclasp: Rotate Ring Puzzle iOS app, served with GitHub Pages at
https://sleepsheeps.github.io/unclasp-site/

App Store Connect has them as the support URL and the privacy policy URL, and AdMob's consent message
names `privacy.html`. It must resolve, or App Store review stops on it.

The privacy policy describes what the app actually does: local storage only (no iCloud), Google AdMob
ads (with the data Google's SDK collects, tracking only with ATT permission, Google's consent form in
the EEA/UK/Switzerland), Game Center leaderboards, no purchase. If the app changes any of that (the
Remove Ads purchase, another ad network, analytics, a permission, notifications), update `privacy.html`,
the support answers in `index.html` and the App Store privacy label in the same change.
